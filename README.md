# La quête de Raphaël — Brevet blanc

Programme de révision interactif pour le brevet blanc des 12 et 13 novembre 2026.

- Page : `index.html` (aucune dépendance, la progression est gardée dans le `localStorage` du navigateur)
- Sauvegarde : export en fichier `.json` ou en code `RAPH1:…`, import depuis l'un ou l'autre
- Poster imprimable : `poster.pdf`
